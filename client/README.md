# MPloyChek Angular client

See the [project README](../README.md) for complete setup, demo credentials, API documentation, and submission instructions.

From this folder, use `npm install` then `npm start` to run the Angular app at `http://localhost:4200`. Run the API in a second terminal as described in the project README.

`npm run build` creates the production bundle. `npm test` runs isolated browser QA with temporary data and cleans up its local servers. It uses Edge by default on Windows; set `CHROME_BIN` to your Chrome/Edge executable when needed. The test suite includes an automated accessibility scan. Results and fixes are documented in [QA_RESULTS.md](../QA_RESULTS.md).
